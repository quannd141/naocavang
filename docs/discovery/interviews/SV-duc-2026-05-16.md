### ❗ Pain 1: Obsidian mạnh nhưng không có spaced repetition tốt
- Có plugin Spaced Repetition nhưng setup phức tạp
- > *"Em note vào Obsidian xong không có cách auto-review. Note cũ bị lãng quên."*

### ❗ Pain 2: Đọc paper KH dài 20-50 trang → khó tổng hợp
- 1 paper Machine Learning thường 30 trang, 1 tuần đọc 3-5 paper
- > *"Em mất 2-3 giờ tóm tắt 1 paper. Tóm xong vẫn quên insight chính sau 1 tháng."*

### ❗ Pain 3: Code snippets + concept khó link với nhau
- Học 1 framework mới → code example + lý thuyết tách rời
- > *"Em muốn link bài note React Hook với code snippet em đã viết. Obsidian làm được nhưng thủ công."*

### ❗ Pain 4: Đồ án tốt nghiệp — quản lý tài liệu lộn xộn
- 50+ paper + 30+ note + 20+ code repo → tìm lại 1 reference cụ thể mất 15 phút
- > *"Em mất 15 phút mỗi lần tìm lại reference cho đồ án."*
